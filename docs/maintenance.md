# 维护与验收

本项目是 Vue 3 + Three.js + TypeScript + Vite 的全屏生长游戏。AI 助手的执行与自动推送规则见 [AGENTS.md](../AGENTS.md)。

## 文件入口

| 位置 | 职责 |
| --- | --- |
| `src/App.vue`、`src/main.ts` | 页面入口、全局样式与错误上报 |
| `src/components/GameView.vue` | 画布、进度、提示、保存和重置按钮 |
| `src/components/ErrorBoundary.vue` | Vue 错误回退界面 |
| `src/core/Game.ts` | 阶段状态机、性能降档、输入、截图和生命周期 |
| `src/core/layers.ts` | 草地、天空、远山、小路、树、房屋、河流、麦田 |
| `src/core/brushes.ts`、`src/core/placement.ts` | 草麦样式几何、画作视野、地面占用和撤销记录 |
| `src/core/materials.ts` | Shader、带状几何和纸纹叠层 |
| `src/core/types.ts` | 图层与输入接口、质量等级、共享辅助函数 |
| `src/core/analytics.ts` | 可选埋点队列与发送 |
| `vite.config.ts`、`tsconfig.json` | 相对资源路径、打包与严格类型检查 |

## 开发命令

首次安装执行 `npm install`，生成并提交 `package-lock.json`；有锁文件后，干净环境使用 `npm ci`。

```bash
npm run dev      # 本地开发
npm run build    # vue-tsc 类型检查，然后 Vite 打包
npm run preview  # 本地检查构建产物
npm run test:core # 笔迹、地面清理、河道/院落保护、撤销、阶段回选和资源释放的逻辑回归检查
```

构建输出为 `dist/`，不纳入 Git。当前 `base: './'` 支持相对资源路径；修改部署路径时需要检查实际资源加载。`test:core` 覆盖核心逻辑，不替代浏览器与触屏验收；当前没有 lint 或 GitHub 部署工作流。

## 按改动影响验收

| 改动 | 必要检查 |
| --- | --- |
| 文档、注释 | 链接、文件路径、脚本名称与描述一致；差异无空白错误 |
| 页面文案、样式、Vue 组件 | `npm run build`；桌面与窄屏检查提示、进度、按钮、回退界面和安全区 |
| 游戏逻辑、输入、图层 | `npm run build`、`npm run test:core`；点按开始、拖动生长、种树、房屋避让与地基留白、路河局部清除和保护、取消/撤销恢复、麦穗弧度及独立方向、八阶段依次完成、完成后回选任意步骤继续添画、重置后再次开始 |
| 材质、Shader、相机、渲染 | `npm run build`；检查纸纹与层次、缩放和横竖屏、截图、后台恢复、降档和减少动态效果 |
| 依赖、构建或部署配置 | 审查依赖及锁文件；`npm run build`；用 `npm run preview` 检查产物与资源路径 |
| 埋点或错误处理 | `npm run build`；检查无端点时可运行、事件字段与发送行为、异常回退；不向真实端点发送测试数据 |

涉及完整游戏体验时，还要确认完成后可以保存 PNG、重新生长，并且重复重置不会明显累积资源或事件。WebGL 不可用或上下文丢失时，确认回退提示和重试路径。触屏体验需要实际触屏设备检查，浏览器窄屏检查不能代替它。

浏览器或设备检查不可用时，报告未覆盖的范围，不把构建通过等同于运行体验通过；需要该项验收的任务先保留本地更改。

## 生长与绘制约定

- 草地与麦田沿整段笔迹按固定距离采样，阶段进度按绘画距离计算；质量降档只减少播种密度，不能改变完成难度。
- `Layer.settled` 表示最后一笔已显示完成，状态机等待松开指针后再切换阶段；尚未进入的图层保持隐藏。八步完成后 `StageMachine.select` 只切换当前画笔，不重建、隐藏或清空已有图层。
- `Layer.tools` 提供该步骤的样式选项，换样式只影响新景物。麦穗方向由 `Layer.directions` 独立选择。草麦实例满 512 株后增加新批次，保留已有矩阵和出生时间，不能循环覆盖旧植物；超出撤销历史且已清除的实例槽位可复用。
- 山按画笔位置生成独立的远、中、近轮廓；路和河保存每笔独立曲线，拖动时每帧至多重建当前笔的几何，显示和地面清除使用同一采样轮廓，结束后不再修改。路河以完整宽度检查保留区，遇到房屋/院落或异类路径就截停，同类路径可汇合；道路还须避开树根。到达前缘的笔画会沿末端方向延伸到视野外，主动停在中间的短笔画保留原端点；取消尚未移动的路径手势不自动延伸。
- `Landscape` 记录植物根部、实际河道/道路轮廓和房屋院落；树屋创建时也记录完整生长轮廓。树屋双向避让，拒绝的位置不计入进度。房屋主体 `renderOrder = 200`，院落留白为 199，其余景物为 0，纸纹为 999。
- 河道逐株清除草麦，树根进入河道时整棵移除，树冠悬在水面上方则保留；清除树时一并取消树根占地。道路和院落清除草麦，麦苗清理根部少量草。后续播种不得进入道路、河道、院落或树根；麦穗与树冠的悬伸不作为水面碰撞依据。
- 每次手势是一个编辑事务；`aAlive` 控制草麦实例的存在状态，撤销和取消完整恢复矩阵、出生时间、占地与景物。完成后的自由添画提供最近 30 笔撤销；当前笔取消、缩放或进入后台时回滚。实体在最后一个历史引用释放后才能销毁，重置/卸载需同时清理 `Landscape` 的历史和索引。
- 透明笔触关闭深度写入，实例网格的主体深度放在 `mesh.position.z`，实例内只保留细微偏移，以保证草、道路、河流和建筑的遮挡顺序。
- 线稿使用 `pencil`、`sketched` 和 `sketchedRibbon` 生成；`aInk` 区分轮廓与填色。草叶、麦穗等独立闭合轮廓分别绘制再合并，避免把不相连的笔画连成框线；`combine` 负责释放合并前的临时几何。
- 动态效果由共享 `uMotion` 控制，并监听系统的减少动态效果偏好；后台暂停时结束当前笔迹，恢复时重新计时，避免误触和错误降档。
- 页面为操作区预留固定高度，提示、进度和完成按钮切换时不应改变画纸尺寸。检查竖屏时确认小路、河流延伸到画纸之外。
